# PLJ visual deck — speaker map

The live page is **almost textless**: film-installation energy. Use this doc while rehearsing. The audience should watch **motion and juxtaposition**; you supply story, names, and specificity.

**Personal assets** (in `public/plj/`) ship with the site when you deploy — fine for a class talk; if you ever need a **private** build, remove or exclude those files from that deploy.

**Live tips**

- **Letters chapter:** PDFs use the built-in browser viewer (toolbar varies). Click the **four dots** at the bottom to change letters. If a browser blocks embedding, open the same path in a new tab: `/plj/letters/…`.
- For **cleaner “snippets”** later, export chosen paragraphs as PNGs and we can swap the iframe for a still carousel (no PDF chrome).
- Revisit `**merge-drag`** mid-talk if you want a second hands-on beat.
- Keyboard: ↑↓, J/K, Home, End between **chapters** (not inside the PDF viewer — click the letter first if you need to scroll the PDF).
